## 👋 About This Repository

Welcome! This repository is my hands-on journey to improve frontend development skills by building small, practical UI components and mini projects.

Instead of only watching tutorials, I practice by creating something small, testing it, improving the design, and pushing the code to GitHub.

- 🎯 **Goal:** Build a strong frontend foundation through daily practice.
- 🧱 **Focus:** Small components and beginner-friendly projects.
- 🛠️ **Technologies:** HTML5, CSS3, and vanilla JavaScript.
- 📈 **Approach:** Learn, build, test, improve, and repeat.

## 🔁 My Workflow

1. 📌 Choose one small component.
2. 🧠 Plan its layout and behavior.
3. 🧱 Build the structure using HTML.
4. 🎨 Style it using CSS and make it responsive.
5. ⚡ Add interactions with JavaScript when needed.
6. 🧪 Test it in the browser and fix issues.
7. 📤 Push the completed work to GitHub.
8. 📝 Update this README with the task and demo link.
